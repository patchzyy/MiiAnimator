# Profile animations

Full-body action reactions keep both feet on the ground and finish in the neutral pose. The window clips are framed for the profile card, with the existing sill at y = 88 and front plane at z = 58 in canonical rig units. They can be followed by a window idle loop.

| Action | Clip | Motion |
| --- | --- | --- |
| `make_primary` | `Make_primary_proud.miianim` | A small anticipation dip, a proud two-palm announcement, and an appreciative nod. |
| `make_primary` | `Make_primary_captain.miianim` | A confident single-palm announcement, a wrist wave, and a polite bow. |
| `rename` | `Rename_introduction.miianim` | Bows before introducing the new name with an open palm and a friendly nod. |
| `rename` | `Rename_delighted.miianim` | Notices the new name, gives a delighted double nod, and presents it with both palms. |
| `change_mii` | `Change_mii.miianim` | Existing two-actor replacement clip. Actor 0 is the new Mii and role `old` is the previous Mii. The saved edited clip is preserved. |
| `window/hello` | `Window_hello_pop.miianim` | Existing spring-up greeting and wave at the sill. |
| `window/hello` | `Window_hello_slide.miianim` | Existing side entrance, bow, and two-handed wave. |
| `window/funny` | `Window_peek.miianim` | Existing peek, duck, pop back up, and wave. |
| `window/funny` | `Window_double_take.miianim` | Two curious glances, a surprised double take, and a playful shrug above the card edge. |
| `window/idle` | `Window_idle_lean.miianim` | Existing loop that leans on the sill and looks around. |
| `window/idle` | `Window_idle_sway.miianim` | Existing gentle sway and glance loop. |

The new action clips return to their starting pose and face, with a short hold at both ends. Their `primary`, `introduce`, `noticed`, `bow`, `acknowledge`, `double_take`, and `shrug` markers identify the readable beats; `done` marks the return to idle. These are optional playback cues. They do not perform the app action themselves.

Only the five new clips are generated by `ProfileExtraAnimationTests.WriteNewProfileAnimations`. That writer does not include the previously authored window animations or `Change_mii.miianim`.

## Quick appear and exit

For switching licenses: the new Mii is in place within about half a second. Entrances start out of sight and end at
rest; exits start at rest and end out of sight (far enough for the shortest Miis). WheelWizard plays an exit, then the
matching entrance, like a carousel (going right: out to the left, in from the right).

| Folder | Clip | Motion |
| --- | --- | --- |
| `quick_appear/from_below` | `Quick_pop_up.miianim` | Springs up from below the sill, squashes and settles with a blink (0.8 s). |
| `quick_appear/from_below` | `Quick_pop_cheer.miianim` | Pops up with a quick two-armed "ta-da" (1.1 s). |
| `quick_appear/from_left`, `from_right` | `Quick_slide_from_*.miianim` | Zips in from the side with a hop, the top half swinging past and rocking back (0.9 s). |
| `quick_exit/to_below` | `Quick_drop_down.miianim` | A tiny hop, then drops below the sill (0.27 s). |
| `quick_exit/to_left`, `to_right` | `Quick_slide_to_*.miianim` | Leans back for a beat, then zips off the side (0.3 s). |

Source: `ProfileQuickAnimations`.
